# agrinho2026larissa
🐛 2. Monitoramento e Proteção Ambiental (Combate a Pragas)
Projetos voltados para reduzir o uso de defensivos químicos, equilibrando a produção e a saúde do ecossistema.
Armadilha Digital para Insetos: Robô ou dispositivo fixo que usa um sensor de luz (LDR) para atrair insetos noturnos em uma lavoura e um sensor ultrassônico para contar a quantidade de pragas capturadas, enviando os dados para uma tela.
App de Triagem de Folhas Doentes: Interface criada no Scratch (ou similar) onde o agricultor clica nos sintomas visíveis da planta (manchas amarelas, furos) e o programa diagnostica se é falta de nutrientes ou uma praga específica, indicando soluções naturais.
